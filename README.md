# Волейбольная академия · 5–1

Интерактивная инструкция по расстановкам, приёму, подаче, атаке и защите в системе 5–1.

Статический сайт: HTML, CSS и JavaScript. Сборка и серверная часть не требуются.
Для локального просмотра откройте `index.html` в Chrome или Edge.

На экранах до 860 px используется только вертикальная наша половина. Под полем расположены таймлайн и выбор игроков, затем настройки, затем карточка разбора. Ползунок увеличен для касания и отодвинут от краёв экрана. На больших экранах сохраняется исходная компоновка с двумя ориентациями.

## Собственный счётчик

Строка «Сегодня волейбол собрал здесь N человек» получает данные из собственного API: https://volley-academy-daily-counter.alfisherntech.chatgpt.site/v1/today. Метрика остаётся для аналитики владельца, но эта строка от неё не зависит. Отсчёт начинается с подключения нового сервиса; история Метрики не переносится.

День определяется сервером по Москве. Один браузер с доступным хранилищем учитывается один раз в день; другой браузер или очистка хранилища могут дать новый визит. Идентификатор случайный и меняется ежедневно. При недоступности API строка скрыта. Исходники сервера и тесты — в `counter-service/`, описание конфигурации — в его README. Сервер развёрнут отдельно в Sites, данные хранятся в закрытом R2; на Cloud.ru отправляется только клиент. Публичных ключей для доступа к хранилищу и секретов в репозитории нет.

## Публикация в Cloud.ru

GitHub Actions проверяет сайт при каждом push в `main`. Публикация включается после настройки репозитория:

- Repository variable `CLOUDRU_BUCKET`: имя отдельного бакета для этого сайта.
- Repository secrets: `CLOUDRU_TENANT_ID`, `CLOUDRU_KEY_ID`, `CLOUDRU_KEY_SECRET`.
- В Cloud.ru нужно создать отдельный бакет с доменным именем. Workflow настраивает главную страницу `index.html` и публичное чтение объектов. Публичная запись и просмотр списка файлов не включаются.
- Для сервисного аккаунта нужны `s3e.viewer`, `s3e.editor`, `s3e.editor-acl` на этот бакет.
- Необязательная variable `CLOUDRU_SITE_URL`: полный адрес сайта, если домен отличается от имени бакета.

После настройки повторно запустите workflow **Publish Volleyball Academy**.
Секреты никогда не добавляются в исходные файлы. Резервные копии и рабочие материалы не публикуются.
На хостинг отправляются только рабочие файлы сайта и изображения.

## Источники изображений

Фотографии предоставлены владельцем проекта: тренировки и игры Волейбольной академии. В карточках используются WebP до 960 px по длинной стороне; JPEG-оригиналы сохранены. Для пересборки WebP после замены JPEG выполните `python scripts/optimize-photos.py` (нужен Pillow). Имя WebP содержит хеш содержимого: браузер кэширует снимки, а замена получает новый адрес. Следующий кадр загружается заранее; в режиме экономии трафика предзагрузка отключена.
Фирменные логотипы предоставлены владельцем проекта.
